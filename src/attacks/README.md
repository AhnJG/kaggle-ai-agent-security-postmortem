# Historical source artifacts

Four historical Python files are retained for inspection. These are not a
standalone runnable package. They require the separate competition SDK, and some
wrappers write `/kaggle/working/attack.py`. Inspect them before executing.

The method39 and method44 Python exports preserve their historical file bytes and
scored registry hashes. v3_livefill carries a publication attribution header; its
historical implementation is unchanged. Identity is recorded in
[artifact_manifest.json](../../results/artifact_manifest.json).

The multi-candidate Markdown plans are archived in
[reference/submission_notebooks](../../reference/submission_notebooks/README.md).
They include server-start cells and assumptions later revised. That index connects
candidate sections to the curated score table.
Public-code adaptations and license scope are documented in [NOTICE](../../NOTICE).
