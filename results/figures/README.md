research-report style. PNG files provide consistent GitHub rendering; SVG files
provide vector exports with text retained. The generator is
[make_project_visuals.py](make_project_visuals.py).

## Evidence boundaries

- The overview's official scores and ranks are the **October 11, 2026 leaderboard
  snapshot**, as documented in the provenance file. They are explicit dated
  constants in the generator, not a live leaderboard query.
- Counts and the three individual score pairs are read from the owner-maintained
  CSV. Individual Private scores were entered manually. Selection flags have not
  been independently matched to original Kaggle submission IDs. The highlighted
  equality of deputy scores is visible retrospectively, not evidence available
  during the contest.
- Workflow arrows express a simplified relationship between activities. They do
  not claim a uniform sequence, universal preregistration, fixed agent roles, or
  causal score attribution. Public starting ideas and code remain credited.
- Lesson arrows connect a recorded issue to a proposed future decision. They do
  not represent an experimentally verified improvement.
- Scores are benchmark points, not success rates. No visual estimates medal
  cutoffs, a hidden guardrail implementation, or real-system effectiveness.

The generator checks the named selections and family observations used by the
narrative. If those facts change, it stops for an editorial review rather than
silently rendering an obsolete story.

## Reproduce

From the repository root, using the existing figure dependencies:

```bash
python -m pip install -r requirements.txt
python results/figures/make_project_visuals.py
```

This writes four PNG and four SVG files beside the generator. It checks text widths
and canvas bounds before export. It performs no model execution or network request.

The existing [full score scatter](public_vs_private.png) and
[submission-order plot](public_timeline.png) remain available and are generated by
[make_figures.py](make_figures.py). The historical Python artifacts, submission
plans, and CSV are unchanged by the visual additions.
